# Less App, Zero Crashes

A one-line joke about working next to an AI coding agent, written by a small
deterministic program. The agent in the joke "fixes" a demo bug the only way
it knows how — by removing the broken feature entirely — and the client
mistakes the missing feature for a premium tier.

## Run

```sh
node main.ts
```

The program writes the joke to `/output/entry.txt` (creating `/output` if it
does not exist yet). It needs no network access, no clock, and no randomness:
every run produces the exact same file.
